# Steering Documentation

This directory contains AI assistant steering documents that provide context and guidelines for working with this codebase.

## Documents

### Core Documentation

- **product.md** - Product overview, key features, and application structure
- **tech.md** - Technology stack, build system, and common commands
- **structure.md** - Project organization, folder structure, and naming conventions

### Development Guidelines

- **key-principles.md** - Core coding principles and patterns
- **typescript-usage.md** - TypeScript conventions and best practices
- **syntax-and-formatting.md** - Code style and formatting rules
- **naming-coventions.md** - File, folder, and component naming standards
- **performance.md** - Performance optimization guidelines
- **ui-and-styling.md** - UI component and styling conventions
- **project-structure.md** - Detailed project structure and module organization

### Maintenance

- **dependencies.md** - Dependency versions, update strategy, and common issues
- **migration-notes.md** - Breaking changes and migration instructions for recent updates

## Purpose

These documents help AI assistants (and developers) understand:
- What this project does
- How it's organized
- What technologies it uses
- How to maintain and update it
- Common patterns and conventions

## Keeping Updated

When making significant changes to the project:
1. Update relevant steering documents
2. Add migration notes for breaking changes
3. Update dependency versions in dependencies.md
4. Document new patterns or conventions

## Template Usage

This is a SaaS starter template. When cloning for a new project:
1. Review and customize product.md for your specific product
2. Update config/index.ts with your app settings
3. Keep tech.md and structure.md as reference
4. Follow the established patterns and conventions
